# D7 — remaining Casual addon author-file comparison

**Checked September 24, 2026. D7 remains open.** This records provenance, byte identity and the resulting direct-source integration; it does not establish permission clearance. The pinned [cueki v1.7.1 release](https://api.github.com/repos/cueki/casual-pre-loader/releases/tags/v1.7.1) supplies `mods.zip` (SHA-256 `bd132d03eda6db17544cb43b5b4b57dc94e0cb91d1ab3de9571faabfce235388`). Its tagged [source URL map](https://github.com/cueki/casual-pre-loader/blob/v1.7.1/data/mod_urls.json) lists particle collections but gives no provenance for the seven addon directories.

I downloaded the exact files listed by each author's GameBanana DownloadPage and confirmed each archive against its API MD5. For the comparison, I read each source VPK's virtual paths and uncompressed entry bytes, checked its per-entry CRC, then compared path and SHA-256 with cueki's `mods/addons/<selection>/` entries. The counts below exclude cueki's `mod.json`. For archives with several optional VPKs, “any VPK” is a generous upper bound: it counts a cueki file as matched if **any** author VPK contains the same path and bytes. It does not establish that one installable option reproduces the selection. The current What's Left of Ye ZIP uses Deflate64; its extracted members were also checked against the ZIP CRC and uncompressed size.

The Developer Textures and Square overlay matches and adapters resolve **source identity for three additional saved choices**. Live GameBanana listing and approved `/dl/` redirect checks passed against the complete pinned archives. Real-author fake-root tests cover Developer alone, with Flat and with a remaining cueki choice; both overlays separately, together and mixed with cueki; profile switch, export/import, Restore stock and missing/corrupt-source no-change behavior. Author archives and install-wide generated VPKs do not enter profile ZIPs; those carry saved selections for recipients to fetch. This does not clear the other choices or underlying creator and Valve-asset questions in the [D7 rights register](d7-asset-rights.md). Native switch auto-fetch has live fetch and core switch coverage separately, but no command-level mock regression; retail TF2 behavior is also unverified. Any further direct-source implementation needs exact source/version matching, current author terms, a migration review for changed bytes, and equivalent state-preservation checks before D7 can be checked.
