These pages describe current terms, not a verified historical revision of each file in cueki's ZIP. The [Skeleton Hotel source](https://gamebanana.com/members/submissions/mods/1414545) is a member listing rather than a specific mod file; the [Vanilla+ source repository](https://github.com/agrastiOs/Ultimate-TF2-Visual-Fix-Pack) has no identified rights file. The URL map covers the nine particle collections but supplies no origin for the ZIP's seven addon directories.

A September 24 decompressed-entry SHA-256 comparison against two current author downloads found that [Square file 1261092](https://gamebanana.com/dl/1261092) matched 109 of 157 corresponding cueki entries; its other 48 entries were `actual_particles/*.pcf`. [TF2 Classic file 1375361](https://gamebanana.com/dl/1375361) matched 8 of 29 entries; 13 PCFs and eight materials differed or were absent. This disproves a byte-identical replacement using those **current** author files, without establishing how every difference arose or ruling out historical versions. The bundle's `WLOY - Gibs + Decals/mod.json` describes cueki's decals as hand-modified. [Saved selections](../../../apps/desktop/src-tauri/core/src/preloader/apply.rs) carry names without author file revisions or per-collection hashes. The Flat and Developer Textures adapters described below preserve their exact game payloads under the existing selection names; [switch preflight](../../../apps/desktop/src-tauri/core/src/preloader/profiles.rs) still requires the exact cached cueki ZIP for other library selections. A direct-origin design for those choices needs exact source/version matching, author terms, an explicit review when old choices would change bytes, and tests for switch, export/import and stock restore before replacing the bundle.

## Implementation choices if grants remain unavailable

- The Venom, TF2Hitsounds and comfig hosted-sound catalogs are retired for new downloads. Native commands refuse the old remote picks, including cached sources. Previously saved VTFs and WAVs remain readable, playable, switchable and exportable from profile-owned bytes; missing local bytes fail without replacing the current pack. A baked boost on a saved remote WAV cannot be changed without a new source. The UI explains these limits and offers first-party, installed-game or user-import choices. This closes the new-download path, not rights for existing exports.
- A saved Casual setup selection of the remaining cueki addons or library particles currently requires a cached, hash-verified `mods.zip` during profile-switch preflight; Flat and Developer Textures use their separate original author archives. Retiring the remaining library needs an explicit review path for those selections so previously saved profiles remain switchable without silently dropping their choices. Profile-owned particle sources, active restore and interrupted-switch recovery must continue to work. No other source in this register is a cleared substitute.
- Viewmodels can still import a user-supplied prebuilt viewmodel VPK. That preserves the ability to use a chosen compatible pack, but it does **not** preserve the current one-click, 64-group builder. Keeping that builder without the CompVMInstaller ZIP requires independently licensed QC/SMD source data covering the same groups, or a new pipeline derived from the player's own installed assets with an independently derived group mapping. Neither substitute has been implemented or validated. Replacing the screenshots with first-party explanatory UI also requires a product review because it would no longer show verified in-game captures. That replacement must also cover the Crosshair scene's `scout_blank` image.
- The [read-only stock-MDL probe](d7-stock-mdl-probe.md) parses nine installed class models and their sequence references, and the [independent mapping study](d7-stock-mapping-study.md) specifies the item-to-activity derivation and retail validation still needed. The [legacy-to-stock compatibility check](d7-viewmodel-local-rebuild-bridge.md) found exact local sequence/animation targets for all 405 legacy stems and six Soldier forced stems on one verified TF2 patch; it is a name-level bridge, not independently derived group semantics or rendered parity. An [audit-only Scout root experiment](d7-scout-root-offset-probe.md) changed one root-position field in a hash-pinned scratch model. A separate [weapon-bone experiment](d7-scout-weapon-bone-probe.md) changed only bounded weapon-position fields in an exact stock Scout animation copy, but found zero-weight sequence cells that limit a hands-visible claim. Neither experiment has a rendered or retail TF2 result or proves a 64-group replacement. The [Valve asset/export review](d7-valve-export-rights.md) records the official TF2 redistribution boundary and the current profile ZIP path. A player-install pipeline must resolve export of transformed Valve model bytes before being called rights-cleared.
- A grant must identify the rights holder, the covered files/revision, allowed display/download/transform/install uses, redistribution terms if any, and any attribution or share-alike obligations. For collected works, check underlying contributors and source-game rights separately. Record the evidence in `THIRD_PARTY.md` and package notices, then test the chosen implementation and existing-profile behavior before checking D7.

The [September 4 owner continuation decision](../../release-0.1.1.md) kept the then-existing integrations for 0.1.1. It explicitly did not claim an author license grant and does not close this audit finding.
