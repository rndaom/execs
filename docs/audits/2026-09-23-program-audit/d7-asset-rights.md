## Implementation choices if grants remain unavailable

- The Crosshair and Sounds panes already have the first-party, installed-game and user-import paths listed above. Removing only the unlicensed curated sources is technically bounded, but it changes the visible catalog and saved selections. Migration must keep old profiles readable and tell users when an existing source cannot be fetched again; it must not silently replace a selected sound or crosshair.
- Viewmodels can still import a user-supplied prebuilt viewmodel VPK. That preserves the ability to use a chosen compatible pack, but it does **not** preserve the current one-click, 64-group builder. Keeping that builder without the CompVMInstaller ZIP requires independently licensed QC/SMD source data covering the same groups, or a new pipeline derived from the player's own installed assets. Neither substitute has been implemented or validated. Replacing the screenshots with first-party explanatory UI also requires a product review because it would no longer show verified in-game captures.
- A grant must identify the rights holder, the covered files/revision, allowed display/download/transform/install uses, redistribution terms if any, and any attribution or share-alike obligations. For collected works, check underlying contributors and source-game rights separately. Record the evidence in `THIRD_PARTY.md` and package notices, then test the chosen implementation and existing-profile behavior before checking D7.

The [September 4 owner continuation decision](../../release-0.1.1.md) kept the then-existing integrations for 0.1.1. It explicitly did not claim an author license grant and does not close this audit finding.
