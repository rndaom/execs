The pinned source map has nine selection entries leading to six unique GameBanana mod pages, one GameBanana member listing and one GitHub repository. GameBanana's current author-set `LicensePage` responses distinguish installing an original mod from redistributing a collection:

These pages describe current terms, not a verified historical revision of each file in cueki's ZIP. The [Skeleton Hotel source](https://gamebanana.com/members/submissions/mods/1414545) is a member listing rather than a specific mod file; the [Vanilla+ source repository](https://github.com/agrastiOs/Ultimate-TF2-Visual-Fix-Pack) has no identified rights file. The URL map covers the nine particle collections but supplies no origin for the ZIP's seven addon directories.

A September 24 decompressed-entry SHA-256 comparison against two current author downloads found that [Square file 1261092](https://gamebanana.com/dl/1261092) matched 109 of 157 corresponding cueki entries; its other 48 entries were `actual_particles/*.pcf`. [TF2 Classic file 1375361](https://gamebanana.com/dl/1375361) matched 8 of 29 entries; 13 PCFs and eight materials differed or were absent. This disproves a byte-identical replacement using those **current** author files, without establishing how every difference arose or ruling out historical versions. The bundle's `WLOY - Gibs + Decals/mod.json` describes cueki's decals as hand-modified. Existing [saved selections](../../../apps/desktop/src-tauri/core/src/preloader/apply.rs) carry names without author file revisions or per-collection hashes, and [switch preflight](../../../apps/desktop/src-tauri/core/src/preloader/profiles.rs) requires the exact cached cueki ZIP for library selections. A direct-origin design needs exact source/version matching, author terms, an explicit review when old choices would change bytes, and tests for switch, export/import and stock restore before replacing the bundle.

## Implementation choices if grants remain unavailable

- The Crosshair and Sounds panes already have the first-party, installed-game and user-import paths listed above. Removing curated sources without item-level rights evidence is technically bounded, but it changes the visible catalog and saved selections. Migration must keep old profiles readable and tell users when an existing source cannot be fetched again; it must not silently replace a selected sound or crosshair. Native fetch commands must follow the same policy as the UI.
- Removing the comfig sound catalog or cueki default mod library also changes visible choices. Existing profile-owned WAVs and installed mod bytes need a keep/clear path. Changing boost on an already boosted TF2Hitsounds or comfig selection currently refetches its original clip; only an unboosted selection can use its installed bytes as the source. A retired fetch must fail with an actionable message rather than silently changing the sound.
- A saved Casual setup selection of cueki addons or library particles currently requires a cached, hash-verified `mods.zip` during profile-switch preflight. Retiring that library needs an explicit review path for those selections so previously saved profiles remain switchable without silently dropping their choices. Profile-owned particle sources, active restore and interrupted-switch recovery must continue to work. No other source in this register is a cleared substitute.
- Viewmodels can still import a user-supplied prebuilt viewmodel VPK. That preserves the ability to use a chosen compatible pack, but it does **not** preserve the current one-click, 64-group builder. Keeping that builder without the CompVMInstaller ZIP requires independently licensed QC/SMD source data covering the same groups, or a new pipeline derived from the player's own installed assets with an independently derived group mapping. Neither substitute has been implemented or validated. Replacing the screenshots with first-party explanatory UI also requires a product review because it would no longer show verified in-game captures. That replacement must also cover the Crosshair scene's `scout_blank` image.
- The [read-only stock-MDL probe](d7-stock-mdl-probe.md) parses nine installed class models and their sequence references, and the [independent mapping study](d7-stock-mapping-study.md) specifies the item-to-activity derivation and retail validation still needed. An [audit-only Scout experiment](d7-scout-root-offset-probe.md) changed one root-position field in a hash-pinned scratch model while preserving all other bytes. It has no rendered or retail TF2 result and does not build a pack or prove a 64-group replacement. A player-install pipeline must also review profile export of transformed Valve model bytes before being called rights-cleared.
- A grant must identify the rights holder, the covered files/revision, allowed display/download/transform/install uses, redistribution terms if any, and any attribution or share-alike obligations. For collected works, check underlying contributors and source-game rights separately. Record the evidence in `THIRD_PARTY.md` and package notices, then test the chosen implementation and existing-profile behavior before checking D7.

The [September 4 owner continuation decision](../../release-0.1.1.md) kept the then-existing integrations for 0.1.1. It explicitly did not claim an author license grant and does not close this audit finding.

### Catalog source refresh, September 24, 2026

The current default heads of the separate Venom texture list and TF2Hitsounds repository still match the pinned revisions in the table. The Venom tree contains texture/material pairs but no per-texture rights or creator ledger; TF2Hitsounds has 32 WAVs and a multi-creator README but no license file. The comfig index contains 1,343 hit and 929 kill sound records with names and hashes, without uploader or rights fields. No exact retained subset of these catalogs has a documented permission chain for its applicable fetch, preview or audition, installation and sound-boost uses.

A separate [GameBanana Bubble Hitsound](https://gamebanana.com/sounds/19000) cites a [CC0 Freesound recording](https://freesound.org/people/blue2107/sounds/59978/), but neither source has been tied by exact bytes or a validated transform to TF2Hitsounds' `bubble.wav` or a comfig index object. It is a provenance lead, not clearance for an existing catalog entry. Retaining any entry needs its original creator/source, pinned file, applicable rights, delivered-byte identity or validated transform, and covered product uses recorded together.
