# Comfig

Comfig manages [mastercomfig](https://comfig.app) for the active profile: the preset, official addons and individual modules. execs downloads mastercomfig's own release packages; it is not affiliated with mastercomfig.

## Presets

| Preset | What it's for |
|---|---|
| Ultra | Highest fidelity. Most demanding. |
| High | High quality for modern systems. |
| Medium | Balanced quality and performance. |
| Low | Fewer effects, higher performance. |
| Custom | No preset. Set each module yourself. |

Profiles that still use a retired preset (Medium High, Medium Low, Destitute) keep it until you pick another one.

## Addons

The addon names say what they do. The less obvious ones:

- **Low memory**: for PCs with little memory.
- **Null-canceling movement**: holding both directions moves the way you pressed last.
- **Flat mouse**: raw input, no acceleration.
- **Transparent viewmodels**: needs DirectX 9 and a HUD that supports it, and turns off anti-aliasing. The same switch appears in Viewmodels.

## Modules

The **Modules** tab lists every mastercomfig module, grouped into Networking, Graphics, HUD and Sound. Search by name, or show one group or only the modules you changed. **Use preset** inherits the preset's value; **Module default** writes mastercomfig's own default for that module even when the preset would set something else.

## Updates

**Update packages** downloads the current mastercomfig release for this profile only. Other profiles keep the version they have until you update them too.

## Profiles without mastercomfig

A profile that doesn't use mastercomfig keeps its own autoexec and class cfgs, and execs leaves them alone. **Try mastercomfig in a new profile** makes a new profile from your current setup with mastercomfig installed; switch back to your old profile at any time.
