## Harness correction prepared for retry

Only the dedicated smoke/client/test scripts are changed. A passive observer records actual trusted pointer/click coordinates, event target and the intended button's stable rectangle/hit test during the zoomed element click. The observer is removed immediately afterward and never substitutes DOM events, focus, clicks or native IPC. An on-target event that fails to open the menu still fails. A missing/untrusted event, changed rectangle, occluded target or unexpected on-target hit also fails rather than being called a driver limitation.

The zoomed keyboard flow is then exercised independently through real bounded Tab/Enter input. The exact observed Choose profile element receives focus through normal tab traversal; the name input and final action are also reached through keyboard input. Normal-scale pointer opening remains required. No profile activation, save/import or game action is added.

Captures now wait for loaded fonts and finished finite animations, cross animation-frame boundaries and require three identical native screenshot buffers with stable dimensions/state. This addresses the observed premature snapshot problem, but still requires inspection of the next run's actual PNGs. Zoom dimensions are written to the report before any later input check can fail.
