# 0.2.0 announcement graphic

`release-0.2.0-x.png` (1600 × 900) is rendered from code, not generated: the
`Announcement` still in `tools/promo/src/Stills.tsx`, with the app's colour
tokens, Inter and the TF2 emblem halftone drawn from the app's own emblem
geometry. Re-render it with `pnpm announcement` in `tools/promo`. The copy is
grounded in the 0.2.0 changelog and README. The X post is in
`release-0.2.0-x.txt`; this prepares the post without sending it.
